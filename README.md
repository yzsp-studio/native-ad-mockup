## 🇨🇳 中文

这个技能为产品生成带真实手机 mock 外框的原生软广静态图。输入可以是上传的产品图、产品页链接，也可以只是文字产品信息，不依赖品牌文件夹、本地产品图目录或预建品牌系统。支持 iMessage/DM、微信风格朋友推荐、小红书种草笔记、评论区问答、商品卡、结账页、低电量弹窗、提醒事项、天气/身体状态、办公聊天、成分卡、倒计时、评价卡、对比卡等格式。生成前先问清是否已有产品图、想要哪种格式，再按手机外框、内屏比例、系统字体、顶部留白与文字可读性规则产出提示词和图片。

### ✨ 能做什么

- 产品图 / 产品页链接 / 文字描述 → 带真实手机外框的原生软广图
- 十余种原生格式：iMessage、微信推荐、小红书笔记、评论区问答、商品卡、结账页、低电量弹窗
- 先问两个问题锁定产品锚点与软广格式，不盲做
- 按手机外框、内屏比例、系统字体、顶部留白、文字可读性规则生成
- 多张参考图自动区分角色：产品图 / 风格参考 / 版式参考 / 场景参考
- 只有文字描述时明确按概念草稿交付，不声称包装完全真实

## 🇬🇧 English

This skill generates native soft-ad static images with a real phone mockup frame around them. Input can be an uploaded product photo, a product page link, or nothing but text about the product, and it does not depend on a brand folder, a local product image directory, or any pre-built brand system. Supported formats include iMessage/DM threads, WeChat-style friend recommendations, Xiaohongshu seeding notes, comment-section Q&A, product cards, checkout pages, low-battery popups, reminders, weather or body-status screens, office chat, ingredient cards, countdowns, review cards, and comparison cards. Before generating anything it asks whether you already have a product image and which format you want, then applies phone frame, inner-screen ratio, system font, top padding, and text-legibility rules to produce prompts and images.

### ✨ What it does

- Product photo, product page link, or plain text in, native soft-ad image with a real phone frame out
- A dozen-plus native formats: iMessage, WeChat recommendations, Xiaohongshu notes, comment Q&A, product cards, checkout pages, low-battery popups
- Asks two questions up front to lock the product anchor and the ad format instead of guessing
- Applies phone frame, inner-screen ratio, system font, top padding, and legibility rules
- Classifies multiple reference images by role: product, style, layout, or scene
- With text only, delivers an explicitly labeled concept draft instead of claiming a real package
